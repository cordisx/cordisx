# Dialog demo

Launch `cordisx dev --config cordisx.config.dialogs.json` from the Host checkout.
This sample uses the public owner-bound service and `cordisx/ui` JSX components.
It exercises preserved context/state, editable body content, header overflow,
footer actions, notification failure, child confirmation, registered views and
Host-rendered form drafts. See [the guide](../../../.agents/docs/dialogs.md).
