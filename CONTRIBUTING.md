# Contributing to CordisX

By submitting a contribution to CordisX core, runtime, CLI, manager, launcher,
adapter, scaffolder, or public interface material, you agree to license that
contribution under `AGPL-3.0-or-later` together with the same
[CordisX Independent Plugin Exception](CORDISX-INDEPENDENT-PLUGIN-EXCEPTION.md).
You retain copyright in your contribution.

CordisX does not require a contributor license agreement for this licensing
model. If the project later wants to offer a separate closed-source dual
license for core code, it must establish an appropriate CLA, copyright
assignment, or other explicit relicensing grant before accepting external core
contributions for that model. This beta does not introduce such a mechanism.

Implementation contributions must also follow [AGENTS.md](AGENTS.md) and the
repository maintenance rules in `.agents/rules/README.md`.
