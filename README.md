# CordisX

让 AI 编程桌面成为属于每个人的可扩展工作台。

CordisX 是一个开源的 AI 编程桌面扩展生态。它希望把原本固定的产品界面，变成一个可以随个人习惯、团队流程和社区创造持续生长的工作空间。

插件可以把常用动作放到最顺手的位置，把项目上下文带到任务旁边，把分散的工具组织成连贯的工作流，也可以为一种全新的协作方式提供完整界面。你不需要重新创造一个 Agent，也不必离开熟悉的工作环境；CordisX 让新的能力直接来到工作发生的地方。

## 愿景

我们相信，AI 编程产品不应该只有一种固定形态：

- 每个人都可以按照自己的思考方式组织工作台；
- 每个团队都可以把内部最佳实践沉淀为可分享的插件；
- 每位开发者都可以通过开放标准发布新的交互、工具与工作流；
- 同一个插件生态可以逐步连接不同的 AI 编程宿主，而不是被某一个产品永久锁定。

CordisX 想做的不只是给界面多加几个按钮，而是让 AI 工作空间拥有真正的可组合性：能力可以被发现、选择、授权、组合和替换，最终形成每个人自己的工作方式。

## 当前阶段

CordisX 仍处于早期实验阶段，目前从 Codex Desktop 的本地扩展体验开始探索。现阶段插件应被视为受信任的本地代码，只应使用你了解并信任的插件。

开发与架构资料见 [.agents/docs](.agents/docs/README.md)。
