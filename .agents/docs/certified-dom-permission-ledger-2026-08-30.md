The worker-ready production result is an execution-boundary invariant, not an
authorization shortcut. The Host never derives it from certification,
Official state, a policy/grant, or a plugin assertion. If the artifact is not
held outside the renderer main realm, native primitives are unavailable, the
worker fails startup, or the generation is replaced, Host DOM availability is
`unavailable` and no bound client survives.

The display-side `MarketplaceModel.snapshot()/subscribe()` API remains excluded
from authorization because its Browser source store, bridge, and JavaScript
objects share the plugin realm. Package lifecycle now consumes only the formal
`LauncherMarketplaceCertifiedAuthority`: a single profile instance reads
Host-owned roots, enforces monotonic revision/revocation, and performs fresh
exact-artifact lookup at plan and apply. Runtime Broker invalidation remains
fed only by the debugger-held future-document endpoint. No renderer-supplied
projection or attestation token is accepted by lifecycle RPC.
